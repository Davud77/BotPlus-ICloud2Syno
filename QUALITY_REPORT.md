# SynologyPhotoSync 1.3.0 — проверка 20 октября 2026

## Изменения

- Активный сеанс ожидает сеть и повторяет текущую операцию после восстановления маршрута. Ожидание учитывает ручную паузу и отмену. Интервалы повторов ограничены 60 секундами; сам сетевой сбой не пропускает файл и не завершает сеанс.
- Повторы охватывают проверку доступа, чтение каталога, SHA-256 оригинала, извлечение Photos, отправку и альбомы. После потери ответа на создание альбома повтор сначала проверяет список по имени.
- Photos 3169 распознаётся как сетевая ошибка, включая вложенные URLError. Внутренняя ошибка −1 и прерывание извлечения имеют максимум две дополнительные попытки. Частичный файл перед каждой попыткой удаляется. Невосстановленный ресурс остаётся ошибкой; повреждённый оригинал не объявляется исправленным.
- Ошибка извлечения одного оригинала при предварительной сверке оставляет его в очереди вместо остановки всей сверки.
- Предупреждения восстановления сохраняются в итоговом состоянии «Требуется внимание». Ошибки пароля, TLS, прав и протокола не повторяются бесконечно.
- Фатальная ошибка во время ручной паузы освобождает завершившуюся задачу и показывает ошибку, вместо зависшего активного сеанса.
- Xcode-проект генерируется по всем Swift-файлам Sources со стабильными ID. Добавлены проверка --check и тест принадлежности исходников целевому модулю. Текущие Debug и Release компилируют типы RemoteMediaInventory.
- Иконка на основе предоставленного образца включена во все размеры macOS AppIcon. Dock остаётся видимым, повторное нажатие открывает настройки.

## Выполненные проверки

- **67 локальных тестов прошли**: всего 69 XCTest, два opt-in теста NAS пропущены в стандартном запуске.
- Новые сценарии: Photos 3169, вложенные сетевые ошибки, ограничение повторов −1, возврат сети при паузе, отмена ожидания/паузы, отказ повторять авторизацию/TLS, повтор запроса с тем же SID, итог сетевого ожидания, фатальная ошибка во время паузы и членство файлов в Xcode target.
- **Один интеграционный тест повторно прошёл на реальном NAS**: диагностический PNG, SHA-256 оригинала, дедупликация, создание и наполнение альбома; собственные объекты очищены, сессия закрыта.
- Строгая проверка конкурентности Swift не выявила предупреждений в Sources/Tests. SwiftPM сообщает только об ограничениях кеша среды проверки.
- Debug и Release успешно собраны: 1.3.0, build 4, arm64, macOS 13+.
- Подпись проверена codesign --verify --deep --strict; hardened runtime включён, get-task-allow отсутствует.
- DMG проверен, содержит AppIcon.icns, LSUIElement=false и ссылку Applications. swift-format, plutil, синтаксис shell и актуальность генератора проверены.

Журналы: [локальные тесты](Validation/Tests.txt), [реальный NAS](Validation/SynologyLiveTests.txt). Сборка Xcode может выдавать служебное предупреждение об отсутствии AppIntents.framework, который приложение не использует.

## Границы проверки

Потеря и восстановление связи, пауза и отмена проверены автоматическими сценариями с подменённым транспортом. Физическое отключение Wi-Fi на пользовательском Mac не выполнялось. Уже запущенное приложение не перезапускалось для проверки интерфейса; Dock проверен по настройкам и ресурсам новой сборки, а не визуальным запуском поверх рабочего сеанса.

Массовая синхронизация медиатеки, реальные Live Photo, большие видео, Shared Space и принудительное управление iCloud не тестировались. Полный каталог NAS был проверен в 1.2.0; в этом проходе повторно проверена только папка диагностического файла. Ошибка −1 может означать проблему конкретного оригинала и после повторов потребовать действий в Photos.

Сохраняются предварительная сверка NAS, частичные соответствия ресурсов, HTTPS, Keychain, ограниченное восстановление сессии, атомарное сохранение и потоковый multipart. Удаления не зеркалируются, App Sandbox не добавлен.
