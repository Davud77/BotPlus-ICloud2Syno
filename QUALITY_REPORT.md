# SynologyPhotoSync 1.2.0 — проверка 19 октября 2026

## Изменения

Перед отправкой приложение читает каталог выбранного пространства Synology Photos, показывает число уже найденных объектов и формирует очередь недостающих ресурсов. Сохранённые ID проверяются по актуальному каталогу. Для файлов со старыми именами совпадение подтверждается размером и SHA-256 оригинала. Компоненты Live Photo учитываются отдельно, частичная загрузка сохраняется атомарно. Первая сверка старых файлов может потребовать загрузки оригиналов из iCloud и NAS; последующие проходы используют сохранённые соответствия.

Исправлены авторизация multipart через Cookie, кодирование строк Synology API и режим дедупликации. Восстановление сессии ограничено одной повторной попыткой; фатальная ошибка останавливает очередь. Секреты хранятся в Keychain, URL не содержит SID, транспорт использует HTTPS.

«Синхронизация завершена» появляется только после полного прохода без ошибок и предупреждений. Пауза, отмена, неполная очередь и восстановленная с предупреждением сессия имеют отдельные состояния. Автоматический повтор после отмены или проблем требует ручного запуска.

## Проверки

- 55 локальных XCTest прошли; два интеграционных теста по умолчанию пропускаются без переменных окружения.
- Отдельно прошли оба теста реального NAS: полный каталог личного пространства и диагностический PNG с проверкой оригинала SHA-256, дедупликации и альбома.
- Созданные тестом объекты удалены по проверенным ID и точным уникальным именам; сессии закрыты.
- Release успешно собран: версия 1.2.0, build 3, arm64, macOS 13+.
- Строгая проверка конкурентности Swift не выявила предупреждений в исходниках. swift-format, plist и синтаксис скриптов проверены.
- Подпись приложения проверена codesign --verify --deep --strict. Hardened runtime включён, get-task-allow отсутствует.
- DMG проверен hdiutil verify и открытием только для чтения. Внутри приложение, ссылка Applications и инструкция установки.

Журналы: [локальные тесты](Validation/Tests.txt), [реальный NAS](Validation/SynologyLiveTests.txt).

DMG, ZIP и контрольная сумма доступны в [GitHub Releases](https://github.com/Davud77/BotPlus-ICloud2Syno/releases/latest). Повторяемые команды описаны в [README.md](README.md). Сборка выполнена Xcode 27.1 / Swift 6.4 вне File Provider; временные кеши и отключение вложенной песочницы компилятора не меняют защиту приложения при запуске.

Подпись локальная ad-hoc. Developer ID и Apple notarization отсутствуют.

## Границы проверки

Массовая синхронизация пользовательской медиатеки не запускалась. Реальные проверки охватывают личное пространство и небольшой PNG; большие видео, реальные Live Photo, Shared Space, извлечение из iCloud и интерфейс требуют отдельных сценариев. Произвольно переименованные файлы без сохранённого соответствия могут не распознаться предварительной сверкой; серверная дедупликация остаётся включённой. Первая сверка по SHA-256 может быть длительной.

Полная синхронизация удалений и App Sandbox не добавлены. Обещать отсутствие всех возможных ошибок по результатам этих проверок нельзя.
