# SynologyPhotoSync 1.4.0 — проверка 21 октября 2026

## Изменения

В настройках постоянно видны версия и номер сборки. Раздел «Система» содержит поиск обновлений и ссылку на релизы. Sparkle 2.10.0 выполняет скачивание, проверку, установку и перезапуск. Версия зависимости и checksum бинарного пакета зафиксированы менеджером пакетов.

Каталог и ZIP подписаны Ed25519. SURequireSignedFeed и SUVerifyUpdateBeforeExtraction включены. Закрытый ключ находится только в Keychain с отдельным account, открытый — в Info.plist. Автоматические фоновые проверки и скрытая установка отключены.

Проверка не запускается во время синхронизации. Если синхронизация началась после проверки, установка ожидает полного завершения задачи. Пауза не освобождает установку. На этапе установки новые запуски синхронизации блокируются, отложенный callback вызывается один раз и очищается при ошибке обновления.

Иконка используется в AppIcon и нижней панели настроек, добавлена в README вместе с двумя настоящими скриншотами интерфейса. Убран оставшийся обработчик, скрывавший Dock при закрытии настроек. Скриншоты сделаны из отдельной сборки SCREENSHOT_PREVIEW с демонстрационными данными; настоящая медиатека, база и пароль NAS не использовались.

## Проверки

- **73 локальных XCTest прошли**, два opt-in теста реального NAS пропущены. На этом этапе серверный протокол не менялся, повторная отправка на NAS не выполнялась.
- Проверены отображение версии, отложенная установка, пауза, однократный callback, отмена обновления, обязательные настройки проверки подписей, правильная подпись и отказ для изменённых данных/чужого ключа.
- **Настоящий установщик Sparkle прошёл полный цикл** проверки подписанного каталога, скачивания подписанного ZIP и замены временного приложения build 4 на build 5. Тестовый ID com.synologyphotosync.update-test; рабочая копия не затрагивалась.
- ZIP с изменённым байтом и прежней длиной отклонён с ошибкой EdDSA до распаковки; старый тестовый build 4 сохранён. Изменённый каталог также отклонён до выбора обновления.
- Сквозные тесты использовали только локальный сервер loopback и одноразовые тестовые приложения. Публичный канал приложения использует HTTPS GitHub и отдельную подпись.
- Release 1.4.0 build 5 успешно собран, arm64, macOS 13+. Проверены codesign --verify --deep --strict, включён hardened runtime; library validation не отключалась. Вложенные компоненты Sparkle сохранены.
- Демонстрационная сборка запущена, проверены раздел обновлений, версия и иконка; два скриншота сохранены для GitHub.
- Проверки swift-format, plutil, актуальности проекта и скриптов пройдены. Строгая проверка конкурентности не сообщает предупреждений в Sources/Tests. Xcode может сообщать о сохранении подписанных бинарных компонентов Sparkle при копировании и отсутствии неиспользуемого AppIntents.framework.

Журналы: [XCTest](Validation/Tests.txt), [установка](Validation/UpdateInstallation.txt), [изменённый ZIP](Validation/UpdateTamperedArchive.txt), [изменённый каталог](Validation/UpdateTamperedFeed.txt).

## Публикация и ограничения

Порядок подписания и публикации — [Docs/Updates.md](Docs/Updates.md). У релиза есть DMG, подписанный ZIP и SHA-256; appcast.xml публикуется после доступности архива.

Первый переход с 1.2/1.3 на 1.4 выполняется вручную через DMG: в старых версиях нет обновлятора. Установка в защищённую папку может потребовать системную авторизацию. Приложение следует скопировать из DMG в Applications. Developer ID и Apple notarization отсутствуют; Ed25519-подпись обновлений их не заменяет.

Полная медиатека, большие видео, Shared Space и реальные пары Live Photo в этом проходе не тестировались. Сохраняются ранее добавленные предварительная сверка NAS, восстановление связи, ручная пауза/отмена и отдельные итоги ошибок и предупреждений.
