# SynologyPhotoSync 1.5.0 — проверка 26 октября 2026

## Параллельные передачи

Настройка «Система → Параллельные передачи» задаёт от 1 до 8 одновременно обрабатываемых файлов; по умолчанию 3. Значение сохраняется и фиксируется на запуск очереди, во время сеанса изменение заблокировано. Каждый файл проходит собственную последовательность iCloud → NAS; разные файлы перекрываются по времени. Части Live Photo остаются последовательными внутри одной задачи.

Очередь держит только выбранное число задач, не создавая отдельную задачу на каждый из десятков тысяч файлов. Фатальная ошибка отменяет соседние задачи; выход из группы ждёт очистки всех активных операций. PhotoKit writeData по-прежнему не предоставляет отмену текущего извлечения, поэтому остановка ожидает его завершения.

У каждого активного файла отдельные прогресс, стадия и идентификатор текущего ресурса. Поздний callback предыдущего ресурса, завершённой или отменённой задачи не меняет состояние. Успех одного файла не очищает прогресс других. Всплывающее окно показывает все активные передачи.

Ожидание сети учитывает отдельные операции: успех одной не снимает ожидание другой. Пауза применяется ко всем задачам, восстановление сети не отменяет ручную паузу. История и подтверждения сохраняются через существующую сериализованную атомарную базу.

Одновременные API-запросы используют один выполняющийся вход в Synology. Запоздавший отказ старого SID переиспользует уже обновлённый SID, вместо нового повторного входа. Ограничение повторного входа на операцию сохранено.

## Проверки

- **83 локальных теста прошли**: всего 85 XCTest, два opt-in теста NAS пропущены.
- Проверено реальное перекрытие асинхронных стадий тестовой очереди при лимитах 1, 3 и 8, без превышения ограничения и пропуска элементов.
- Проверены отмена до старта и во время работы, очистка задач при фатальной ошибке и общая пауза.
- Проверены сохранение настройки, границы диапазона, независимость прогресса и сетевых ожиданий, поздние callbacks и счётчики успехов.
- Проверены конкурентные запросы: один начальный вход и один общий повторный вход при истечении SID.
- Release 1.5.0 build 6 собран для arm64, macOS 13+. Строгая проверка конкурентности не выявила предупреждений в Sources/Tests.
- Демонстрационная Debug-сборка запущена: в интерфейсе проверено изменение количества 3 → 4 → 3, сохранён скриншот настройки. Рабочее приложение не перезапускалось.
- swift-format, plutil и проверка состава Xcode-проекта пройдены. DMG и архив для обновления проверяются и подписываются существующим процессом Sparkle.

## Ограничения

Массовая параллельная выгрузка пользовательской медиатеки и замер пропускной способности реального NAS не выполнялись. Прирост скорости зависит от iCloud, NAS, сети и диска. Число временных извлечённых ресурсов и multipart-копий ограничено числом активных задач, но крупные видео требуют соответствующего свободного места.

Предварительная сверка каталога NAS остаётся последовательной. Она выполняется перед параллельной очередью и не занимает её слоты. Альбомы обрабатываются после полной очистки файловой очереди.

Версия 1.5.0 распространяется через существующий подписанный канал Sparkle; в 1.4 доступна из настроек. Developer ID и Apple notarization отсутствуют, подпись обновлений Ed25519 их не заменяет.
